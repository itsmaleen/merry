# cmux-companion WebSocket Protocol

Version: 1

All messages are JSON, newline-delimited over WebSocket text frames.

## Authentication

All WebSocket connections must include an `Authorization` header:

```
Authorization: Bearer <token>
```

Token is generated by the bridge on first run and exchanged via QR pairing.

## Server → Client: Push Events

### notification.created

Sent when cmux receives a new notification.

```json
{
  "type": "notification.created",
  "data": {
    "id": "uuid",
    "title": "Claude Code",
    "subtitle": "Permission",
    "body": "Approval needed for file write",
    "workspace_id": "uuid",
    "surface_id": "uuid-or-null",
    "is_read": false
  }
}
```

### notification.cleared

Reserved. Intended to signal that all notifications were cleared. **Not currently
emitted by the bridge** — `notification.clear` (a client command) only resets the
poller's seen-ID set; no push is broadcast. The iOS client already handles this
event, so a future bridge can broadcast it after a successful clear without a
client change.

```json
{
  "type": "notification.cleared",
  "data": {}
}
```

### cmux.connected

Sent when the bridge (re)connects to the cmux socket.

```json
{
  "type": "cmux.connected",
  "data": { "bridge_version": "0.1.0" }
}
```

### cmux.disconnected

Sent when the bridge loses its cmux socket connection.

```json
{
  "type": "cmux.disconnected",
  "data": { "reason": "socket_unavailable" }
}
```

### connected

Sent immediately after WebSocket handshake + auth succeeds.

```json
{
  "type": "connected",
  "data": {
    "bridge_version": "0.1.0",
    "cmux_connected": true,
    "protocol_version": 1
  }
}
```

## Client → Server: Commands

Commands use the cmux v2 JSON-RPC envelope. The bridge proxies them to the cmux socket and returns the response.

**Request:**
```json
{"id":"1","method":"METHOD","params":{...}}
```

**Response:**
```json
{"id":"1","ok":true,"result":{...}}
{"id":"1","ok":false,"error":{"code":"ERROR_CODE","message":"human readable"}}
```

### Supported Methods (Phase 1)

**Workspaces:**
- `workspace.list` — list all workspaces
- `workspace.current` — get current workspace
- `workspace.select` — `{"workspace_id":"..."}`
- `workspace.create` — `{"name":"optional"}`

**Surfaces:**
- `surface.list` — `{"workspace_id":"..."}` (optional, defaults to current)
- `surface.focus` — `{"surface_id":"..."}`
- `surface.create` — `{"type":"terminal"}` (or "browser", creates in focused pane)
- `surface.split` — `{"direction":"right","surface_id":"..."}` (direction: left/right/up/down)
- `surface.close` — `{"surface_id":"..."}`
- `surface.read_text` — `{"surface_id":"...","lines":N}` returns the last N rows
  **including terminal scrollback** (so a large N yields history directly);
  `{"scrollback":true}` returns the full scrollback. Optional `workspace_id`.
  Returns `{"text":"...","base64":"...", ...}`. Full-screen TUIs (e.g.
  claude-code) repaint a fixed viewport and keep little/no terminal scrollback,
  so for those it returns roughly the visible screen regardless of N. Used by
  the iOS live-view + scrollback rendering.

**Agents (bridge-local, not proxied to cmux):**
- `agent.transcript` — `{"surface_id":"...","max_messages":300,"known_fingerprint":"..."}`
  → `{"supported":true,"agent_kind":"claude","text":"...","session_id":"...",
  "session_title":"...","session_missing":false,"fingerprint":"...","unchanged":false,
  "source":"hook_store_session"}`. Also answers to its old name `claude.transcript`.

  Renders the conversation of whatever agent a surface is running. Claude Code
  and opencode are both full-screen TUIs that keep no terminal scrollback, so
  `surface.read_text` only ever returns their current screen — the conversation
  has to come from the agent's own session store. The iOS app renders this as
  the surface's card content, with the live screen appended below it.

  `supported` is false for a surface with no agent the bridge can read; the
  client uses that to tell an agent surface from a plain terminal, since cmux's
  own metadata names only Claude Code.

  **Claude Code** is bound through cmux's hook session store
  (`~/.cmuxterm/claude-hook-sessions.json`), which records the `transcript_path`
  Claude reports per session along with its surface. `source` is
  `hook_store_surface`, `hook_store_session`, `projects_glob`, or `cwd_latest`.

  **opencode** carries no cmux binding at all — cmux's opencode plugin is opt-in
  and usually absent — and stores its conversation in SQLite
  (`~/.local/share/opencode/opencode.db`), not per-session files. So the bridge
  identifies it in two independent steps: it is an opencode surface if cmux's
  terminal table (`debug.terminals`) gives the surface a tty and that tty has an
  opencode process on it; and the conversation is the session whose directory
  matches the surface's and whose title the surface's title (`OC | <title>`,
  truncated) is a prefix of. `source` is `opencode_title_cwd`, or
  `opencode_unidentified` when opencode is running but its surface title names
  no session yet — a fresh opencode, before its session has a title. Several
  opencode surfaces routinely share a working directory, so an unidentified
  session renders as empty rather than as whichever session in that directory
  was touched last.

  `fingerprint` identifies the rendering. Pass it back as `known_fingerprint`
  and an unchanged transcript answers `unchanged: true` with no `text`, which is
  what makes polling this on every refresh cycle cheap.

**Browsers:**
- `browser.url.get` — `{"surface_id":"..."}` → `{"url":"..."}` (browser surfaces)

**Workspaces (continued):**
- `workspace.close` — `{"workspace_id":"..."}`

**Panes:**
- `pane.list` — `{"workspace_id":"..."}` (optional, defaults to current)
- `pane.focus` — `{"pane_id":"..."}`

**Input:**
- `surface.send_text` — `{"surface_id":"...","text":"ls\n"}`
- `surface.send_key` — `{"surface_id":"...","key":"ctrl+c"}`

**Notifications:**
- `notification.list` — list all notifications
- `notification.clear` — clear all notifications

**System:**
- `system.ping` — health check, returns `{"pong":true}`
