## Findings

### FINDING 1 — PATH TRAVERSAL via `checkpoint_id` (HIGH)

**File:** `bridge/internal/claude/transcript.go:101`

**Trigger:** `filepath.Join` calls `filepath.Clean` internally. If `checkpoint_id` contains `../` sequences, Clean resolves them against the literal `*` component before the pattern ever reaches `Glob`. The `*` is stripped out by the `..` resolution and the pattern becomes a concrete path outside `~/.claude/projects`.

Verified with actual Go:
```
filepath.Join("/home/user/.claude/projects", "*", "../../../etc/passwd.jsonl")
// → "/home/user/etc/passwd.jsonl"  (no wildcard, stat'd directly by Glob)

filepath.Join("/home/user/.claude/projects", "*", "../../../../etc/passwd.jsonl")
// → "/home/etc/passwd.jsonl"
```

A `checkpoint_id` of `"../../../etc/passwd"` causes `Glob` to stat and return `/home/user/etc/passwd.jsonl` if it exists. With enough `../` the path can reach any file on the filesystem that ends in `.jsonl` — but since the attacker controls the suffix via the value appended before `.jsonl`, any file at a path reachable from `~` can be targeted.

**Severity:** High (defense-in-depth basis; cmux is trusted-local, but a compromised cmux socket or a bug in cmux's session metadata could turn this into an information-disclosure channel for any `.jsonl` file accessible to the bridge process).

**Fix** — validate `checkpoint_id` at the top of `resolveTranscriptPath`, before constructing the pattern:

```go
// Reject anything that isn't a plain filename component (no separators, no ..)
if strings.ContainsAny(checkpointID, "/\\") || checkpointID == ".." || checkpointID == "." {
    return "", fmt.Errorf("invalid checkpoint_id")
}
```

Or, more strictly, enforce a UUID/hex-only shape with a regexp:
```go
var sessionIDRe = regexp.MustCompile(`^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$`)
if !sessionIDRe.MatchString(checkpointID) {
    return "", fmt.Errorf("checkpoint_id format invalid")
}
```

Additionally, after Glob, verify the returned path is actually inside `projectsDir`:
```go
if !strings.HasPrefix(filepath.Clean(matches[0])+string(filepath.Separator), projectsDir+string(filepath.Separator)) {
    return "", fmt.Errorf("resolved path escapes projects directory")
}
```

### FINDING 2 — GLOB WILDCARD INJECTION via `checkpoint_id` (MEDIUM)

**File:** `bridge/internal/claude/transcript.go:101`

**Trigger:** `checkpoint_id = "*"` produces pattern `projectsDir/*/*.jsonl`, which `filepath.Glob` expands to every `.jsonl` across every project directory. `matches[0]` returns the first (alphabetically) match — effectively a cross-session data leak. `checkpoint_id = "?"` or `checkpoint_id = "[abc]xyz"` also inject into the glob pattern.

This is a separate issue from path traversal: there's no `..` involved, just special glob metacharacters (`*`, `?`, `[...]`).

**Severity:** Medium (cross-session data disclosure within `~/.claude/projects`).

**Fix:** The same UUID/no-separator validation above also closes this, since UUID characters are `[0-9a-f-]` and contain none of `*?[`.

### FINDING 3 — NO FILE SIZE GUARD BEFORE `os.ReadFile` (MEDIUM)

**File:** `bridge/internal/claude/transcript.go:69`

**Trigger:** `info.Size()` is available from the preceding `os.Stat` (line 56) but is only used for cache invalidation. There is no check of the form `if info.Size() &gt; maxFileBytes { ... }` before `os.ReadFile`. A transcript file of several hundred MB (common for a long Claude Code session) is read entirely into memory. `renderJSONL` then additionally does `string(data)` (another copy) and `strings.Split` (a `[]string` view into that copy), potentially holding 2–3x the file size in working memory before `capTail` trims the rendered output to 128 KB.

**Severity:** Medium DoS (affects the bridge process; not externally triggered — requires a large transcript on disk).

**Fix:** Add a size cap between `Stat` and `ReadFile`:

```go
const maxTranscriptFileBytes = 32 * 1024 * 1024 // 32 MB

if info.Size() &gt; maxTranscriptFileBytes {
    // Read only the tail 32 MB — Claude session files grow forward,
    // so the end is the current conversation.
    f, err := os.Open(transcriptPath)
    if err != nil {
        return "", true, sessionID, err
    }
    defer f.Close()
    tail := make([]byte, maxTranscriptFileBytes)
    n, _ := f.ReadAt(tail, info.Size()-maxTranscriptFileBytes)
    data = tail[:n]
} else {
    data, err = os.ReadFile(transcriptPath)
    ...
}
```

Or more simply: `os.ReadFile` → `readFileTail(path, 32MB)` unconditionally.

### FINDING 4 — NO UPPER BOUND ON CLIENT-SUPPLIED `max_messages` (LOW)

**File:** `bridge/internal/ws/handler.go:175–176`

**Trigger:** A WebSocket client sends `{"max_messages": 10000000}`. The handler accepts any `v &gt; 0` without a cap. `renderJSONL` will then collect up to 10M messages into the `messages []msg` slice before slicing it. This is bounded by the actual line count in the file, but combined with a large transcript file (finding 3), a single request could drive significant CPU and memory usage.

**Severity:** Low (authenticated WebSocket clients only; local context).

**Fix:**
```go
const maxAllowedMessages = 2000
if v, ok := cmd.Params["max_messages"].(float64); ok &amp;&amp; v &gt; 0 {
    maxMessages = int(v)
    if maxMessages &gt; maxAllowedMessages {
        maxMessages = maxAllowedMessages
    }
}
```

### FINDING 5 — TOCTOU between `os.Stat` and `os.ReadFile` (LOW / INFORMATIONAL)

**File:** `bridge/internal/claude/transcript.go:56–69`

**Trigger:** The file could change between `os.Stat` (line 56) and `os.ReadFile` (line 69). In that case the bridge reads the new content but stores a `cacheEntry` with the old `modTime`/`size` from the pre-change stat. The next request will re-stat, see a mismatch, and re-read correctly. So this does **not** cause permanent cache poisoning or data loss — it just means one cache round might store a `(new content, old metadata)` entry that gets invalidated on the next hit.

**Severity:** Low / informational. No fix strictly required, but if desired, re-stat after ReadFile and use those values for the cache entry.
